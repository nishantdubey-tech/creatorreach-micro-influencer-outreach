# Generated data

The CSVs are created by the live `discover` command. They are intentionally not prefilled with fictional creator records: the assignment prohibits fabricated identities and metrics. `influencers.csv` contains every returned live channel candidate and explicit pass/fail reasons. `shortlisted_messages.csv` includes those passing configured filters. Emails not publicly found are marked `Not Found`; audience demographics unavailable from the public API are marked `Not Available`. The SQLite outreach database and tracker are created by `simulate-send`.
